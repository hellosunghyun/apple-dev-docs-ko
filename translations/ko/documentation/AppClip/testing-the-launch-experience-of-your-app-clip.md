# <span class="ko-segment" data-segment-id="seg:heading:testing-the-launch-experience-of-your-app-clip:0000:0001">App Clip 실행 경험 테스트</span>

<span class="ko-segment" data-segment-id="seg:paragraph:testing-the-launch-experience-of-your-app-clip:0001:0001">**프레임워크**: App Clips</span>

<span class="ko-segment" data-segment-id="seg:paragraph:testing-the-launch-experience-of-your-app-clip:0002:0001">App Clip 호출을 디버깅하고, 실행 경험을 테스트하며, 릴리스된 App Clip의 구성을 확인합니다.</span>

#### <span class="ko-segment" data-segment-id="seg:heading:overview:0003:0001">Overview</span>

<span class="ko-segment" data-segment-id="seg:paragraph:overview:0004:0001">빠른 실행 경험은 App Clip이 제공하는 사용자 경험에 필수적입니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:overview:0004:0002">결과적으로 호출 URL을 선택하고 App Store Connect에서 App Clip 경험을 구성한 다음 호출 URL을 처리할 코드를 작성하는 데 상당한 시간을 할애하게 됩니다.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:overview:0005:0001">App Clip이 매끄러운 실행 경험을 제공하고 App Clip 경험 구성이 올바른지 확인하려면 다음 테스트와 검증을 사용합니다:</span>

- <span class="ko-segment" data-segment-id="seg:list:overview:0006:0001">개발 중에는 디버깅용 invocation URL을 구성하기 위해 <code>_XCAppClipURL</code> 환경 변수를 사용합니다.</span>
- <span class="ko-segment" data-segment-id="seg:list:overview:0006:0002">테스트 기기에서 로컬 경험을 생성한 뒤 호출 시 App Clip 카드와 App Clip 실행 경험을 검증합니다.</span>
- <span class="ko-segment" data-segment-id="seg:list:overview:0006:0003">다른 사용자와 베타 버전 공유가 준비되면 <a href="https://developer.apple.comhttps://developer.apple.com/testflight/">@@TOKEN_0@@</a>에서 테스트 대상으로 App Clip 경험을 생성합니다.</span>
- <span class="ko-segment" data-segment-id="seg:list:overview:0006:0004">App Store에 App Clip을 게시한 후에는 iPhone의 App Clip diagnostics를 사용해 App Clip 구성을 검증합니다.</span>

##### <span class="ko-segment" data-segment-id="seg:heading:debug-your-app-clip:0007:0001">App Clip 디버깅</span>

<span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0008:0001">invocation URL은 App Clip의 사용자 인터페이스를 사용자의 컨텍스트에 맞게 업데이트할 수 있어 빠르고 즉시 실행되는 App Clip 경험을 제공하는 데 핵심 역할을 합니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0008:0002">이 코드를 테스트하는 것이 특히 중요합니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0008:0003">Xcode에서 디버깅용 invocation URL을 제공합니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0008:0004">그다음 코드가 예기치 않은 invocation URL을 포함한 모든 invocation URL을 처리하고, 사용자 컨텍스트에 맞게 App Clip의 사용자 인터페이스를 업데이트하는지 확인합니다.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0009:0001">디버깅용 invocation URL을 구성하려면:</span>

1. <span class="ko-segment" data-segment-id="seg:list:debug-your-app-clip:0010:0001">Xcode에서 <code>Product &gt; Scheme &gt; Edit Scheme</code>을 선택하고 App Clip의 스킴을 선택합니다.</span>
2. <span class="ko-segment" data-segment-id="seg:list:debug-your-app-clip:0010:0002"><code>Run</code> 작업을 선택합니다.</span>
3. <span class="ko-segment" data-segment-id="seg:list:debug-your-app-clip:0010:0003"><code>Arguments</code> 탭에서 <code>_XCAppClipURL</code> 환경 변수가 있는지 확인합니다. 프로젝트에 App Clip 대상을 추가하면 Xcode가 자동으로 추가합니다. 누락된 경우 환경 변수를 추가합니다.</span>
4. <span class="ko-segment" data-segment-id="seg:list:debug-your-app-clip:0010:0004">환경 변수 값을 테스트할 invocation URL로 설정합니다.</span>
5. <span class="ko-segment" data-segment-id="seg:list:debug-your-app-clip:0010:0005">변수 옆의 체크박스를 선택해 변수를 사용하도록 설정합니다.</span>
6. <span class="ko-segment" data-segment-id="seg:list:debug-your-app-clip:0010:0006">테스트 URL은 <a href="https://developer.apple.com/documentation/Foundation/NSUserActivity">@@TOKEN_0@@</a> 개체에서 접근하도록 App Clip을 빌드하고 실행해 확인합니다. invocation URL 접근 방법은 <a href="responding-to-invocations.md">@@TOKEN_1@@</a>을 참조합니다.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0011:0001">다음 스크린샷은 <code>_XCAppClipURL</code> 환경 변수 값을 사용해 App Clip 대상의 <code>Run</code> 동작을 구성하는 시트를 보여 줍니다.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0012:0001">![App Clip 대상의 <code>Run</code> 동작을 구성하는 시트를 보여 주는 스크린샷.</span> <span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0012:0002"><code>_XCAppClipURL</code> 환경 변수 값은 설정되었지만 활성화되지 않았습니다.](https://docs-assets.developer.apple.com/published/f183530078eba0a42a3d61fa51ea8197/media-3671997%402x.png)</span>

<span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0013:0001">Xcode로 App Clip을 디버그하면 <code>_XCAppClipURL</code> 변수에 설정한 값으로 App Clip이 즉시 실행됩니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0013:0002">App Clip 카드는 표시되지 않습니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:debug-your-app-clip:0013:0003">테스트할 때 호출에서 App Clip 카드를 확인하고 전체 실행 경험을 검증하려면 테스트 기기에 로컬 경험을 등록합니다.</span>

##### <span class="ko-segment" data-segment-id="seg:heading:test-app-clip-invocations-with-a-local-experience:0014:0001">로컬 경험으로 App Clip 호출 테스트</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0015:0001"><code>_XCAppClipURL</code> 환경 변수를 활용하면 invocation URL을 처리하는 코드를 디버그할 때 유용합니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0015:0002">그러나 여러 가지 호출에서 App Clip이 빠르고 신뢰할 수 있는 실행 경험을 제공하도록 해야 합니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0015:0003">또한 App Clip 카드는 사용자가 App Clip을 실행할 때의 첫 상호작용이므로 이미지, 텍스트, call-to-action 동사를 검토하는 것이 특히 중요합니다.</span>

> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0016:0001">**참고**: 로컬 경험은 개발 중 App Clip의 실행 경험을 테스트하는 데 매우 효과적인 방법입니다.</span> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0016:0002">단, 로컬 경험을 사용하면 전체 앱이 설치된 사용자가 호출할 때 App Clip이 아닌 앱이 실행되는 시나리오도 테스트할 수 있습니다.</span> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0016:0003">invocation URL이 전체 앱을 실행할 수 있는지 확인하려면 universal links를 사용합니다.</span> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0016:0004">자세한 내용은 아래 <a href="testing-the-launch-experience-of-your-app-clip#Test-the-launch-experience-of-the-full-app-during-development.md">@@TOKEN_0@@</a> 항목을 참조하세요.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0017:0001">개발 중에 호출을 테스트하고 App Clip 카드의 디자인을 검토하려면 테스트 기기에서 로컬 경험을 구성합니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0017:0002">로컬 경험을 사용하면 다음과 같이 App Clip을 실행할 수 있습니다:</span>

- <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0018:0001">작성한 App Clip Code, QR 코드 또는 NFC 태그를 스캔해 로컬 경험을 실행합니다. 테스트용 App Clip Code 생성 방법은 <a href="creating-app-clip-codes-with-the-app-clip-code-generator.md">@@TOKEN_0@@</a>를 참조하세요. QR 코드를 만들거나 NFC 태그를 쓰려면 선호하는 도구를 사용합니다.</span>
- <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0018:0002">웹사이트에 추가한 Smart Banner 또는 Safari 또는 <a href="https://developer.apple.com/documentation/SafariServices/SFSafariViewController">@@TOKEN_0@@</a>에서 표시되는 App Clip 카드를 탭합니다.</span>
- <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0018:0003">Smart App Banner가 표시되는 웹사이트 링크를 공유합니다. 메시지 발신자를 테스트 기기의 연락처에 추가해야 합니다.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0019:0001">참고: <a href="https://developer.apple.com/documentation/BundleResources/Entitlements/com.apple.developer.associated-domains">@@TOKEN_0@@</a> 또는 App Clip과 웹사이트의 연동을 구성할 필요 없이 App Clip Code, QR 코드, NFC 태그로 로컬 경험을 실행할 수 있습니다.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0019:0002">However, testing invocations from a Smart App Banner or the App Clip card in Safari comes with prerequisites; for example, you need to associate your website with your App Clip, submit a version of your app with an App Clip for review to App Store Connect, and release it in the App Store after approval.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0019:0003">To learn more about when the Smart App Banner appears and for information on supporting invocations from your website or the Messages app, refer to <a href="supporting-invocations-from-your-website-and-the-messages-app.md">@@TOKEN_0@@</a>.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0019:0004">To verify your configured App Clip experiences for a released app and App Clip, refer to <a href="testing-the-launch-experience-of-your-app-clip#Verify-the-configuration-of-your-released-App-Clip.md">@@TOKEN_0@@</a> below.</span>

> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0020:0001">💡 **Tip**: Add the Code Scanner and the NFC Tag Reader to Control Center by opening the Settings app and selecting Control Center.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0021:0001">To test your launch experience with a local experience:</span>

1. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0001">Build and run your App Clip on your test device to make sure it’s cached on the test device. For example, with the Fruta sample code project, follow the instructions to configure it, then run the <code>Fruta iOS Clip</code> scheme. To download the sample code project, visit <a href="fruta-building-a-feature-rich-app-with-swiftui.md">@@TOKEN_1@@</a>.</span>
2. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0002">On your test device, open the Settings app, navigate to the iOS developer settings by choosing Developer &gt; Local Experiences, and select Register Local Experience.</span>
3. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0003">Enter the invocation URL you want to test. In some cases, it may be a simple URL prefix like <code>https://fruta.example.com</code>. It can also be a longer invocation URL with path and query parameters.</span>
4. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0004">Enter the bundle ID of your App Clip.</span>
5. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0005">Provide a title and a subtitle. For the Fruta sample code project, you could enter <code>Order a smoothie.</code> as the title and <code>It’s yummy!</code> as the subtitle.</span>
6. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0006">Select a call-to-action; for example <code>Open</code>.</span>
7. <span class="ko-segment" data-segment-id="seg:list:test-app-clip-invocations-with-a-local-experience:0022:0007">Choose a photo you want to use as the App Clip card’s header image.</span>

> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0023:0001">**Note**: In addition to building and running your App Clip on your test device to cache it on the device, you can also manually add the <code>.ipa</code> file of your App Clip to the device.</span> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0023:0002">First, archive the full app that corresponds with your App Clip.</span> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0023:0003">Then, in Xcode, export the App Clip for Ad Hoc or Development distribution.</span> <span class="ko-segment" data-segment-id="seg:blockquote:test-app-clip-invocations-with-a-local-experience:0023:0004">Finally, drag the exported <code>.ipa</code> file to a connected device that appears in the Devices and Simulators window.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0024:0001">The following screenshot shows the interface you use to configure a local experience on iPhone:</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0025:0001">![A screenshot of an iPhone that shows the interface for configuring a local experience.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0025:0002">It uses https://example.com as the URL prefix and com.example.app.clip as the bundle identifier.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0025:0003">The title for the local experience’s App Clip card is Example App, its subtitle is A local App Clip experience, and its call-to-action verb is Open.](https://docs-assets.developer.apple.com/published/2a952ad63d25ae376798d8dc31152766/settings-local-experience%402x.png)</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0026:0001">When you configure a local experience on a device, the local experience takes precedence over App Clip experiences you configure in <a href="https://developer.apple.comhttps://appstoreconnect.apple.com/login">@@TOKEN_0@@</a>.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0026:0002">However, local experiences only launch an App Clip that’s signed for Development, Ad Hoc, or TestFlight distribution.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0026:0003">They don’t launch an App Clip or full app that’s published on the App Store.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-app-clip-invocations-with-a-local-experience:0026:0004">Remember to remove the local experience before testing App Clip experiences you configure in App Store Connect.</span>

##### <span class="ko-segment" data-segment-id="seg:heading:test-the-launch-experience-of-the-full-app-during-development:0027:0001">Test the Launch Experience of the Full App During Development</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0028:0001">Local App Clip invocations help you test the launch experience of your App Clip while you develop it in Xcode.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0028:0002">However, local invocations don’t allow you to test the launch experience of the full app from an App Clip invocation.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0028:0003">The best way to verify that your full app can handle App Clip invocations as you would expect is to use universal links and the invocation URL of your App Clip as the link’s URL.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0028:0004">Both App Clips and universal links make the launch URL available as part of the user activity object.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0028:0005">If a Universal Link opens your app to the App Clip experience you expect, you can be sure that the launch experience from the App Clip card to your full app works correctly.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0029:0001">For more information about debugging and testing universal links, refer to <a href="https://developer.apple.com/documentation/Technotes/tn3155-debugging-universal-links">@@TOKEN_0@@</a>.</span> <span class="ko-segment" data-segment-id="seg:paragraph:test-the-launch-experience-of-the-full-app-during-development:0029:0002">For general information about universal links, refer to <a href="https://developer.apple.com/documentation/Xcode/supporting-universal-links-in-your-app">@@TOKEN_0@@</a>.</span>

##### <span class="ko-segment" data-segment-id="seg:heading:create-app-clip-experiences-for-testers-in-testflight:0030:0001">Create App Clip Experiences for Testers in Testflight</span>

<span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0031:0001">A reliable user experience is crucial to App Clips and requires spending time to test all user flows and supported invocations.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0031:0002">To help make sure your App Clip works as expected, you can make your App Clip available to testers in <a href="https://developer.apple.comhttps://developer.apple.com/testflight/">@@TOKEN_0@@</a>.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0031:0003">First, upload an app with an App Clip to <a href="https://developer.apple.comhttps://appstoreconnect.apple.com/login">@@TOKEN_0@@</a>.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0031:0004">Then, in App Store Connect, navigate to the uploaded build.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0031:0005">In the App Clip section, you can configure up to three different App Clip experiences for testing.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0031:0006">Note that the App Clip card doesn’t appear for App Clip experiences you create in TestFlight.</span>

> <span class="ko-segment" data-segment-id="seg:blockquote:create-app-clip-experiences-for-testers-in-testflight:0032:0001">❗ **Important**: Unlike local experiences, creating an App Clip experience for testers in TestFlight requires you to associate your App Clip with your website.</span> <span class="ko-segment" data-segment-id="seg:blockquote:create-app-clip-experiences-for-testers-in-testflight:0032:0002">For more information on configuring associated domains, refer to <a href="associating-your-app-clip-with-your-website.md">@@TOKEN_0@@</a>.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0033:0001">Users don’t install App Clips, and App Clips don’t appear on the Home Screen.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0033:0002">Similarly, testers don’t install the beta version of your App Clip, and it also doesn’t appear on the Home Screen either.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0033:0003">Instead, testers launch the App Clip experiences you configure for testing through the <a href="https://developer.apple.comhttps://apps.apple.com/us/app/testflight/id899247664">@@TOKEN_0@@</a> on their device.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0034:0001">For more information on configuring experiences for testing in App Store Connect, refer to <a href="https://developer.apple.comhttps://help.apple.com/app-store-connect/#/devbc57e2ec6">@@TOKEN_0@@</a>.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0035:0001">Testers can also configure a local experience to launch the App Clip you distribute with TestFlight.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0035:0002">However, you must still associate your App Clip with your website so testers can launch it from the TestFlight app.</span> <span class="ko-segment" data-segment-id="seg:paragraph:create-app-clip-experiences-for-testers-in-testflight:0035:0003">In addition, testers must launch the App Clip from an App Clip experience you configure for testing in App Store Connect at least once to ensure that the App Clip is cached on the device.</span>

##### <span class="ko-segment" data-segment-id="seg:heading:remove-cached-advanced-app-clip-experiences:0036:0001">Remove Cached Advanced App Clip Experiences</span>

<span class="ko-segment" data-segment-id="seg:paragraph:remove-cached-advanced-app-clip-experiences:0037:0001">When you create a new advanced App Clip experience in App Store Connect, the new experience may not work right away because iOS caches App Clip experiences.</span> <span class="ko-segment" data-segment-id="seg:paragraph:remove-cached-advanced-app-clip-experiences:0037:0002">To make sure an invocation launches a new App Clip experience, open the Settings app, navigate to the Developer section, and choose Clear Experience Cache.</span>

##### <span class="ko-segment" data-segment-id="seg:heading:verify-the-configuration-of-your-released-app-clip:0038:0001">Verify the Configuration of Your Released App Clip</span>

<span class="ko-segment" data-segment-id="seg:paragraph:verify-the-configuration-of-your-released-app-clip:0039:0001">When you’ve uploaded your app version with an App Clip, it has passed App Store review, and you’ve released the version in the App Store, verify the configuration of your App Clip experiences to be sure that your website displays the Smart App Banner and that the App Clip appears on users’ devices:</span>

1. <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0040:0001">Configure a default and optional advanced App Clip experiences in <a href="https://developer.apple.comhttps://appstoreconnect.apple.com/login">@@TOKEN_0@@</a> and release the version of your app that contains the App Clip on the App Store.</span>
2. <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0040:0002">On iPhone, open the Settings app, and navigate to the iOS developer settings by choosing Developer.</span>
3. <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0040:0003">Choose Diagnostics in the App Clips Testing section.</span>
4. <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0040:0004">Enter the URL of the website you associated with your App Clip and that you use for your App Clip experiences — for example, <code>https://fruta.example.com</code>.</span>

<span class="ko-segment" data-segment-id="seg:paragraph:verify-the-configuration-of-your-released-app-clip:0041:0001">When you enter a URL, the system verifies your App Clip configuration and indicates whether you:</span>

- <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0042:0001">Registered an advanced App Clip experience</span>
- <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0042:0002">Published your App Clip on the App Store</span>
- <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0042:0003">Associated your App Clip with the entered URL</span>
- <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0042:0004">Picked an invocation URL that fits into an App Clip Code</span>
- <span class="ko-segment" data-segment-id="seg:list:verify-the-configuration-of-your-released-app-clip:0042:0005">Added a Smart App Banner to your website</span>

<span class="ko-segment" data-segment-id="seg:paragraph:verify-the-configuration-of-your-released-app-clip:0043:0001">If the system found issues with your configuration, the App Clip diagnostics functionality on iPhone indicates errors and offers links to App Clip documentation to help resolve issues.</span> <span class="ko-segment" data-segment-id="seg:paragraph:verify-the-configuration-of-your-released-app-clip:0043:0002">Note that advanced App Clip experiences and displaying a Smart App Banner on your website are optional but recommended steps that help users discover your App Clip.</span>
